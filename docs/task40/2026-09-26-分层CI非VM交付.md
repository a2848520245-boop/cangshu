# 任务 40 分层 CI 非 VM 实现交付（2026-09-26）

笔记库 `M1-任务表.md` 是唯一正式台账；本轮任务 40 为「进行中／未验」。本页记录分层 CI 的代码与本机局部验证，不把配置解析或脚本单测当成 `ACC-CI`／`DOC-CI` 通过。真实 PostgreSQL／浏览器 job 未手动调度。

## 实现范围

- `.github/workflows/ci.yml` 将 push／PR 的 `pr-gate` 与手动 `real-e2e` 分开。自动层无数据库 service，运行无 DB Java 测试、后端编译、任务 31 纯脚本回归、前端单测／构建和 Chromium 模拟交互；命令失败使步骤失败，`always()` 保留可用日志产物。工作流触发器会在公开交付分支推送时自动运行；结果须以远端 Actions 实际 run 判定。
- `ci-test-selection.py` 显式分类当前 20 个无 DB 测试、12 个 PostgreSQL 测试和 1 个支持类。新增或缺失 Java 源码、重名、分类重叠、无 DB 组出现数据库上下文时拒绝；真实层则运行完整 Maven 测试。
- `real-e2e` 仅在 `workflow_dispatch` 且 `run_real_e2e=true` 时调度。入口还限制 GitHub Actions 仓库、事件和显式标记；PostgreSQL service 绑定 loopback 指定端口，准备测试库与独立 UI 库，真实浏览器使用独立数据根。本轮没有 dispatch。
- `ci-child-process.mjs` 集中处理 JAR 与 Playwright 顶层子进程的 `error`／`exit`／`close`，区分信号退出和未退出进程，超时后才升级 SIGKILL；JAR 健康探测使用绝对截止时间。它没有证明 Chromium 后代进程树均被收束。

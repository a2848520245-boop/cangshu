# 任务 39 非 VM 实现交付（2026-09-26）

本页只记录最小浏览器闭环的实现和本机局部验证。笔记库 `M1-任务表.md` 是唯一正式台账：任务 39 为「进行中／未验」。隔离 VM 上的真实浏览器、Spring Boot 与 PostgreSQL 联合验收尚未运行，`ACC-UI`／`ACC-HTTP` 不因此通过。

## 实现范围

- Vue 3／TypeScript／Vite 前端提供上传、列表与名称／标签检索、详情、下载与基础预览、回收站查看／还原／清空；沿用既有 API，同源打入 Spring Boot JAR，不增业务接口。
- 加载、上传、下载、详情、还原、清空失败均给出可见反馈；重复点击上传／清空时防止重复提交。列表搜索与翻页保持过滤条件，迟到响应不会覆盖新结果；搜索、切换视图、打开其他详情及成功软删／还原时清除旧预览，避免这些路径显示陈旧内容。
- 下载前使用已有内容端点的 `HEAD` 做状态预检。后端新增 MockMvc 契约测试，覆盖存在资源的状态及下载头、不存在资源的 404；MockMvc 会缓存 GET 处理器用于 HEAD 的内容，因此无法证明真实网络不传响应体。
